TOOLS

使うツールの全体像

開発から公開までに5つのツールを使います。まず「自分のPCの中でやること（ローカル）」と「インターネット側でやること（クラウド）」の2つに分けて覚えると、迷わなくなります。

ローカルとクラウド

ローカル自分のPC内・手を動かす場所

① Cursor コードを書く 編集する ② GitHub Desktop 保存して送る
プッシュ クラウドへ送る

クラウドインターネット側・保管と公開

③ GitHub コードを保管する 自動で反映 ⑤ Netlify サイトを公開する 公開
出口 公開サイト お客様が見る画面
サイトがデータを読む ④ Supabase 会員情報や投稿などのデータ置き場。サイト本体ではない

お客様に説明するときは「作る場所」「置く場所」「見せる場所」と言い換えると伝わります。ツール名を先に出すと、それだけで身構えられます。

1本の流れで見る

順番 ツール ここで何が起きるか
① Cursor 自分のPCの中にあるサイトのファイルを直す。この時点では、直したのは自分のPCだけ。
② GitHub Desktop 直した内容に名前をつけて保存（コミット）し、クラウドへ送る（プッシュ）。
③ GitHub 送られたコードが保管される。誰がいつ何を直したかが残る。
④ Netlify GitHubの更新を見つけて、自動で公開サイトを作り直す。数分でURLに反映される。
⑤ Supabase 公開されたサイトが、会員情報や投稿データをここから読み書きする。

Supabaseだけは流れの外にあります。①→②→③→⑤が「サイトそのもの」を運ぶ道で、④は「サイトが使うデータ置き場」です。Cursorで直しても、Supabaseの中身は変わりません。
